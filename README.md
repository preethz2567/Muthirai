# Muthirai

> A production-ready monorepo with three independently Dockerized services — a React/Vite frontend, a public-facing FastAPI + SQLAlchemy API, and a stateless FastAPI agent-worker for embedding and scoring.

---

## Architecture

```
Muthirai/
├─ frontend/                 React + Vite + Tailwind  →  :5173 (nginx :80 inside Docker)
├─ services/
│  ├─ api/                   FastAPI — database + public routes  →  :8000
│  │  ├─ app/
│  │  │  ├─ routes/          /health, /items
│  │  │  ├─ models/          SQLAlchemy ORM models
│  │  │  └─ db/              Session factory (SQLite default, swap for Postgres)
│  │  ├─ requirements.txt
│  │  └─ Dockerfile
│  └─ agent-worker/          FastAPI — stateless embedding + agent logic  →  :8001
│     ├─ app/
│     │  ├─ agents/          /agents/embed, /agents/run
│     │  ├─ scoring/         /scoring/score
│     │  └─ routes/          /health
│     ├─ requirements.txt
│     └─ Dockerfile
├─ docker-compose.yml
└─ README.md
```

### Service Roles

| Service | Port | Responsibility |
|---|---|---|
| **frontend** | `5173` (host) / `80` (container) | React SPA served via nginx |
| **api** | `8000` | Public-facing REST API; owns the SQLite/Postgres database; calls `agent-worker` via `http://agent-worker:8001` |
| **agent-worker** | `8001` | Stateless worker; handles text embedding and agent/scoring logic; no direct DB access |

### Inter-Service Communication

```
Browser ──► frontend (nginx :80)
                │
                └──► api (:8000)  ──► agent-worker (:8001)
                          │
                      Database (SQLite / Postgres)
```

All three services share the `muthirai-net` Docker bridge network. The **api** service reaches **agent-worker** using the internal DNS name `http://agent-worker:8001` — no IP addresses needed.

## Quick Start

### Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) ≥ 4.x
- `docker compose` v2 (`docker compose version`)

### Run everything

```bash
# From the repo root
docker compose up --build
```

This will:
1. Build each service image from its `Dockerfile`.
2. Start **agent-worker** first (api depends on its healthcheck passing).
3. Start **api** (frontend depends on api's healthcheck passing).
4. Start **frontend** once api is healthy.

### Verify health

```bash
# API service
curl http://localhost:8000/health
# → {"status":"ok","service":"api"}

# Agent-worker service
curl http://localhost:8001/health
# → {"status":"ok","service":"agent-worker"}

# Frontend (served by nginx)
curl -I http://localhost:5173
# → HTTP/1.1 200 OK
```

### Stop everything

```bash
docker compose down
```

To also remove the persistent DB volume:

```bash
docker compose down -v
```

## Development (without Docker)

### API

```bash
cd services/api
python -m venv .venv && source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Agent Worker

```bash
cd services/agent-worker
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8001
```

### Frontend

```bash
cd frontend
npm install
npm run dev
# → http://localhost:5173
```

## Environment Variables

| Variable | Service | Default | Description |
|---|---|---|---|
| `DATABASE_URL` | api | `sqlite:///./muthirai.db` | SQLAlchemy connection string |
| `AGENT_WORKER_URL` | api | `http://agent-worker:8001` | Internal URL for the agent-worker |

## Extending the Project

- **Swap SQLite for Postgres**: set `DATABASE_URL=postgresql://user:pass@host/db` and add `psycopg2-binary` to `services/api/requirements.txt`.
- **Add a real embedding model**: uncomment `sentence-transformers` in `services/agent-worker/requirements.txt` and update `app/agents/__init__.py`.
- **Add authentication**: add an `auth` router to `services/api/app/routes/` using `python-jose` + `passlib`.
